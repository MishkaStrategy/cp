# PYTHON // NIGHT SYSTEM

Изолированное коммерческое предложение для **Python Lounge**.

## Концепция

Premium nightlife / hospitality digital system: почти чёрная среда, graphite/glass UI, дозированный venom green, editorial typography и пластичная «траектория Python» вместо буквальных изображений змеи.

Коммерческое предложение частично работает как будущий сайт: внутри есть интерактивные режимы `Smoke / Bar / Music / Private / Night`, mobile preview и frontend-демонстрация бронирования.

## Файлы

- `index.html` — семантическая структура предложения
- `styles.css` — responsive visual system и motion
- `script.js` — reveal, scroll progress, hero depth, mode switcher, booking demo
- `assets/favicon.svg` — локальный favicon
- `package.json` + `build.mjs` — dependency-free production validation

## Проверка

```bash
npm run build
```
