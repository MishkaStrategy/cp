# Telegram stickers (90)

Prepared from the supplied contact sheet for Telegram static sticker import.

- 90 static WebP stickers
- 512 x 512 px transparent canvas
- one sticker per file
- filenames: `sticker_001.webp` ... `sticker_090.webp`
- all files are below Telegram's static-sticker size limit

The source sheet has inconsistent printed numbering and a few flattened/overlapping designs, so files are numbered in visual reading order. The complete ZIP archive was generated in the ChatGPT task that created this directory.
