# Душа — коммерческое предложение

Персональная web-презентация / digital-концепция для «Души», Новосибирск, пр. Карла Маркса, 57.

## Концепция

«У “Души” уже есть главное. Дадим ему цифровую форму.»

Визуальный язык строится вокруг тепла, приватности, мягкого света и ощущения «третьего дома», которое повторяется в отзывах гостей. В проекте намеренно нет чужих интерьерных фотографий: визуальные зоны собраны как абстрактные placeholders, чтобы реальные фото заведения можно было заменить без перестройки макета.

## Технически

- vanilla HTML / CSS / JS;
- никаких framework-зависимостей;
- относительные пути, совместимые с `/cp/dusha/`;
- `prefers-reduced-motion`;
- семантическая разметка, focus states, skip link;
- `noindex,nofollow` для клиентского КП;
- адаптация от 320px до широких desktop-экранов.
