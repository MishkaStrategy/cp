# Душа V2

Вторая самостоятельная версия коммерческого предложения для lounge bar «Душа».

## Концепция

Центральная идея: **«Чужая душа — потёмки»** — слоган заведения используется как драматургия интерфейса, а не просто как декоративная фраза.

Вместо космической / орбитальной метафоры V1 используется человеческая и эмоциональная система: темнота → присутствие → пульс → свет → раскрытие → действие.

Визуальные принципы:
- глубокий угольный и графитовый фон;
- тёплый молочный текст;
- дозированный красный неон как «пульс» интерфейса;
- абстрактная душа, собранная CSS-формами без чужих фотографий;
- мягкие reveal / breathing / pulse анимации;
- editorial typography + premium hospitality;
- без планет, орбит и стереотипного кальянного неона.

## Файлы

- `index.html` — структура и контент;
- `styles.css` — дизайн, адаптив и motion;
- `script.js` — reveal, progress, pointer-light и micro-interactions.

## Responsive

Основные сценарии рассчитаны на 320px+ и широкий desktop. Горизонтальные процессные блоки на планшете аккуратно становятся скроллируемыми, а на мобильном перестраиваются в вертикальную структуру.

## Accessibility

Есть skip-link, семантическая структура, focus-friendly ссылки и `prefers-reduced-motion`.

V1 остаётся в `../dusha/` и не изменяется.
