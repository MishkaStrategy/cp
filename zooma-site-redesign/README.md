# ZOOMA — source-site redesign

Новый независимый redesign, созданный **с нуля по структуре исходного ZOOMA Casino**, а не на базе предыдущих макетов из репозитория.

## Source structure preserved

- Casino lobby
- Wheel
- Mines
- Classic
- Duels
- Турниры
- The Trains!
- Промокод
- История
- Вопросы и ответы
- Провайдеры
- Поиск
- Chat / account UI

## Design direction

Сохранён характер исходного продукта: тёмный compact casino UI, фиксированный левый sidebar, яркие game artworks, плотная сетка, небольшие badges и отдельные сервисные разделы. Изменения ограничены улучшением иерархии, адаптива, поиска, кликабельности и состояний.

## Important

Это UI prototype. Реальные wagering, игровые, регистрационные и платёжные API не подключены.
