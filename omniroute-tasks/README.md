# OmniRoute Tasks

Служебная зона для задач, которые ChatGPT HQ отправляет на OmniRoute/Codex worker.

Назначение:
- хранить устойчивый технический anchor/provenance для runtime-задач;
- при необходимости хранить промпты и итоговые отчёты;
- не смешивать служебные worker-задачи с существующими проектами репозитория.

Структура:
- `prompts/` — сохранённые постановки задач при необходимости;
- `reports/` — итоговые отчёты worker при необходимости.

Для Figma runtime-задач фактическим source of truth и target остаётся указанный Figma-файл. GitHub используется только как control/provenance plane.
