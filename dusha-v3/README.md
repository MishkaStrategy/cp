# Душа — V3 / BODY · SOUL

Третья самостоятельная digital-концепция коммерческого предложения для «Души» в Новосибирске.

## Концепция

**BODY / SOUL**

- красный = тело / тепло / физическое пространство;
- ледяной голубой = душа / воздух / цифровая форма;
- дым = переход между физическим и ощущаемым;
- слоган: «Чужая душа — потёмки. Ваша — нет.»;
- главный объект: абстрактная двойная форма «Душа», реагирующая на движение указателя.

## Что реализовано

- immersive hero;
- BODY / SOUL split-анализ;
- путь гостя «до первого вдоха»;
- FEEL / SEE / CHOOSE / ENTER;
- интерактивный mini-demo будущего сайта;
- light / motion / optional sound concept;
- состав проекта и этапы;
- три конфигурации без выдуманной цены;
- responsive 320+;
- `prefers-reduced-motion`;
- keyboard/focus states;
- без внешних JS/CSS-зависимостей.

## Источник фактов

Публичная карточка 2GIS «Душа», проспект Карла Маркса, 57, Новосибирск. Проверено 16.08.2026. Изменяемые счётчики оценок намеренно не зафиксированы как постоянный факт.

## Статус

V3 существует отдельно от `/dusha/` (V2), чтобы предыдущая версия оставалась доступной для сравнения.
