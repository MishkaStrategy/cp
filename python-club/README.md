# PYTHON — Night Skin

Premium commercial-proposal landing for **Python**, Novosibirsk. This is a proposal for the club owners and a mini-prototype of a future digital presence — not the visitor website itself.

## Concept

**Night Skin** translates the Python name through motion rather than literal snake imagery: obsidian and bottle-green surfaces, champagne metal, rare crimson tension, curved light, stage geometry and slow editorial choreography. The page deliberately avoids the generic black/red nightclub template.

The narrative starts with the strengths already visible in Python's public digital footprint, identifies the gap between the offline atmosphere and online presentation, and then demonstrates a future-site direction with guest scenarios, conversion logic and desktop/mobile interface mockups.

## Research basis

Public sources used for factual context:

- 2GIS listing and reviews for Python, Yadrintsevskaya 21;
- official Telegram channel `@nsk_python`;
- public club page / current promotion listing;
- public venue descriptions and review platforms.

No fabricated growth metrics, awards, testimonials or agreed prices are used.

## Structure

- cinematic commercial hero;
- existing strengths and digital gap;
- new role of the website;
- Night Skin art direction;
- interactive guest scenarios;
- embedded desktop + mobile future-site prototype;
- conversion architecture;
- scope and eight-step process;
- realistic outcome framing;
- project-format CTA and final screen.

## Stack

Static semantic HTML, CSS and vanilla JavaScript. No framework, no build step and no external animation library. All project-owned assets use relative paths so the page works under the GitHub Pages subpath. Motion respects `prefers-reduced-motion`.

## Local run

```bash
cd python-club
python3 -m http.server 8080
```

Open `http://localhost:8080`.
