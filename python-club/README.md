# PYTHON — Nocturnal Instinct

Premium commercial-proposal landing for **Python**, Novosibirsk. The page presents a new digital direction for the club rather than acting as the club's visitor website.

## Concept

**Nocturnal Instinct** translates the Python name without literal snake imagery: curved light, dark glass, satin, bottle green, champagne accents and slow editorial motion. The narrative moves from the strength of the existing offline product to the gap in digital presentation, then demonstrates the future site through an embedded concept prototype.

## Structure

- commercial hero and brand thesis;
- existing strengths and digital gap;
- new role of the website;
- Nocturnal Instinct art direction;
- guest scenarios;
- embedded future-site prototype;
- conversion architecture;
- scope, process and outcomes;
- project-format CTA and final screen.

## Stack

Static semantic HTML, CSS and vanilla JavaScript. No build step and no framework. Relative asset paths are used so the project works under the GitHub Pages subpath.

## Local run

```bash
cd python-club
python3 -m http.server 8080
```
